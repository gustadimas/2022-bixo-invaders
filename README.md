# Bixo Invaders

Atividade da faculdade de set/2022 a out/2022. Publiquei anos depois (nov/2026) e não atualizei nada.

Shooter no estilo Space Invaders que fiz nas oficinas de jogos da faculdade. O histórico tem duas versões: o primeiro commit é o Bixo Invaders de setembro de 2022 e o segundo é a versão de outubro, que na época salvei como OficinasGame.

Os scripts têm "Tudo" no nome (`script_shipTudo.cs`, `script_enemyTudo.cs`) porque cada um cuidava de praticamente tudo daquela parte do jogo.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2020.3.36f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
